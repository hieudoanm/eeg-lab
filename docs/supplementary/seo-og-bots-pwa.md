# SEO, Open Graph, Bots, and PWA Configuration

This document describes the search engine optimisation, social sharing, bot management, and progressive web app configuration implemented in NeuroLab.

## 1. Open Graph (OG) Metadata

### 1.1 Purpose

Control how NeuroLab appears when shared on social platforms (LinkedIn, Twitter, Slack, Discord, etc.) and in link previews.

### 1.2 Implementation

**File:** `packages/frontend/src/app/layout.tsx`

```typescript
export const metadata: Metadata = {
  title: { default: 'NeuroLab', template: '%s | NeuroLab' },
  description:
    'Neuroscience research platform for EEG studies, datasets, and descriptive analyses.',
  openGraph: {
    type: 'website',
    locale: 'en_US',
    url: 'https://neurolab.example.com',
    siteName: 'NeuroLab',
    title: 'NeuroLab',
    description:
      'Neuroscience research platform for EEG studies, datasets, and descriptive analyses.',
    images: [
      {
        url: '/og/og.png',
        width: 1200,
        height: 630,
        alt: 'NeuroLab — EEG signal visualisation with three-channel brain wave preview'
      }
    ]
  },
  twitter: {
    card: 'summary_large_image',
    title: 'NeuroLab',
    description:
      'Neuroscience research platform for EEG studies, datasets, and descriptive analyses.',
    images: ['/og/og.png']
  }
};
```

### 1.3 OG Image

**Files:**

- `packages/frontend/public/og/og.svg` — Source vector graphic
- `packages/frontend/public/og/og.png` — 1200×630 px raster for social platforms

**Design:** Minimal three-wave EEG visualisation (alpha, beta, gamma bands) centred on a neutral background with the NeuroLab wordmark. The SVG source allows lossless editing; the PNG is generated via sharp at build time.

**Generation script:** `packages/frontend/scripts/generate-og.ts`

```bash
cd packages/frontend && pnpm tsx scripts/generate-og.ts
```

## 2. Sitemap

### 2.1 Purpose

Help search engines discover all public and authenticated routes.

### 2.2 Implementation

**File:** `packages/frontend/src/app/sitemap.ts`

```typescript
export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const baseUrl =
    process.env.NEXT_PUBLIC_APP_URL ?? 'https://neurolab.example.com';

  const staticRoutes = ['', '/login'].map((path) => ({
    url: `${baseUrl}${path}`,
    lastModified: new Date(),
    changeFrequency: 'weekly' as const,
    priority: path === '' ? 1 : 0.8
  }));

  // Authenticated routes are included with lower priority
  // In production, these would be dynamically generated from the database
  const authRoutes = [
    '/app/dashboard',
    '/app/studies',
    '/app/analyses',
    '/app/settings/profile',
    '/app/settings/organisation'
  ].map((path) => ({
    url: `${baseUrl}${path}`,
    lastModified: new Date(),
    changeFrequency: 'daily' as const,
    priority: 0.5
  }));

  return [...staticRoutes, ...authRoutes];
}
```

**Output:** `/sitemap.xml` (auto-generated by Next.js)

## 3. Robots.txt

### 3.1 Purpose

Control crawler access to the site, including blocking AI training crawlers.

### 3.2 Implementation

**File:** `packages/frontend/src/app/robots.ts`

```typescript
export default function robots(): MetadataRoute.Robots {
  const baseUrl =
    process.env.NEXT_PUBLIC_APP_URL ?? 'https://neurolab.example.com';

  return {
    rules: [
      {
        userAgent: '*',
        allow: ['/', '/login'],
        disallow: ['/app/', '/api/']
      },
      {
        userAgent: 'GPTBot',
        disallow: ['/']
      },
      {
        userAgent: 'ChatGPT-User',
        disallow: ['/']
      },
      {
        userAgent: 'CCBot',
        disallow: ['/']
      },
      {
        userAgent: 'anthropic-ai',
        disallow: ['/']
      },
      {
        userAgent: 'Claude-Web',
        disallow: ['/']
      },
      {
        userAgent: 'PerplexityBot',
        disallow: ['/']
      }
    ],
    sitemap: `${baseUrl}/sitemap.xml`,
    host: baseUrl
  };
}
```

**Output:** `/robots.txt` (auto-generated by Next.js)

**Blocked AI crawlers:**

- GPTBot (OpenAI)
- ChatGPT-User (OpenAI)
- CCBot (Common Crawl)
- anthropic-ai / Claude-Web (Anthropic)
- PerplexityBot (Perplexity)

## 6. PWA (Progressive Web App)

### 6.1 Purpose

Enable installability, offline-capable caching, and native-like experience.

### 6.2 Implementation

**File:** `packages/frontend/next.config.ts`

```typescript
const withPWA = require('next-pwa')({
  dest: 'public',
  register: true,
  skipWaiting: true,
  disable: process.env.NODE_ENV === 'development',
  runtimeCaching: [
    {
      urlPattern: /^https:\/\/fonts\.googleapis\.com\/.*/i,
      handler: 'CacheFirst',
      options: {
        cacheName: 'google-fonts',
        expiration: { maxEntries: 10, maxAgeSeconds: 60 * 60 * 24 * 365 }
      }
    },
    {
      urlPattern: /^https:\/\/fonts\.gstatic\.com\/.*/i,
      handler: 'CacheFirst',
      options: {
        cacheName: 'google-fonts-static',
        expiration: { maxEntries: 10, maxAgeSeconds: 60 * 60 * 24 * 365 }
      }
    },
    {
      urlPattern: /\.(?:png|jpg|jpeg|svg|gif|webp|ico)$/i,
      handler: 'CacheFirst',
      options: {
        cacheName: 'images',
        expiration: { maxEntries: 50, maxAgeSeconds: 60 * 60 * 24 * 30 }
      }
    }
  ]
});

module.exports = withPWA({
  // ... rest of Next.js config
});
```
